# DeepSeek Harness Adapter Layer

[中文](README.md)

This directory is Agent Harness's **DeepSeek Harness (dsh) adapter layer**, sibling
to `.claude-plugin/` (Claude Code), `.codex-plugin/` (Codex), and `.pi/` (Pi),
following the same philosophy: **the top-level `skills/` directory is the single
source of truth; each platform only adds a thin adapter layer, and none of them
affect each other.**

## Install (choose one)

### Option A: Use inside the repository (zero install)

`.dsh/skills` is a symlink to the top-level `skills/`. `cd` into this repository
and start dsh — DSH auto-discovers the project-level skills directory
(`<projectRoot>/.dsh/skills`); **19 skills are directly invocable** (`auto-loop`
is not a standard skill and is skipped; the 11 process skills carry top-level
`disable-model-invocation` semantics and are not loadable under DSH — use the
preset or `--user-skills` for the full 30):

```bash
cd agent-harness
dsh web
```

### Option B: One-command global install (usable in any project)

```bash
bash scripts/install-dsh.sh          # install the agent preset
bash scripts/install-dsh.sh --user-skills   # additionally install user-level skills (available in any preset)
bash scripts/install-dsh.sh --check  # dry-run: show status
bash scripts/install-dsh.sh --uninstall     # uninstall
```

After installing:

1. Start `dsh web` and switch to the **Agent Harness workflow** preset in the
   preset list;
2. or just use the default preset — the user-level skills
   (`~/.dsh/skills/agent-harness/`) appear in the available skills catalog
   under any preset.

## Layout

```
.dsh/
├── skills -> ../skills          # project-level symlink: works out of the box
├── README.md                    # Chinese docs
├── README_EN.md                 # this file
└── agent-preset/                # distribution unit, copied to ~/.dsh/.agent-presets/agent-harness/
    ├── preset.yml               # preset manifest (name/description/order)
    ├── agent.cordis.yml         # composition: persona + tool rows + skills mount
    └── skills/                  # DSH-flavored copy (generated by the sync script — do not edit by hand)
```

## Behavioral differences from the Claude Code version

| Capability | Claude Code version | DeepSeek Harness version |
|---|---|---|
| Session-start injection | `hooks/session-start` injects `using-agent-harness` | preset `persona` prompt section (see `agent.cordis.yml`) |
| Skill loading | `Skill` tool | `skill` tool (catalog auto-injected into the model view) |
| Ralph loop | `/ralph-loop` slash command | native `ralph` tool (enabled in the preset) |
| Subagent definitions | `agents/code-reviewer.md` | full prompts passed to the `subagent` tool per skill body |
| Skill format | `when_to_use` (snake_case) | `whenToUse` (camelCase, converted in the copy) |

## Maintenance

- **Changing skills:** only edit the top-level `skills/<name>/`, then run
  `bash scripts/sync-dsh-skills.sh` to regenerate the copy (it automatically
  converts `when_to_use` → `whenToUse` and skips the non-standard `auto-loop`
  skill).
- **Verification:** `bash tests/dsh-plugin-sync/run-all.sh` (pure script
  assertions, seconds, no model quota consumed).
- **Do not** hand-edit files under `.dsh/agent-preset/skills/` — the sync
  script overwrites them.
