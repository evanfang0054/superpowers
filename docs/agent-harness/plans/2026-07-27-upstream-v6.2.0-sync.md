# Upstream Superpowers v6.2.0 Sync Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use agent-harness:subagent-driven-development (recommended) or agent-harness:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 从 upstream superpowers v6.2.0 cherry-pick + 人工合并吸收 bugfix、Codex 基础设施与 skill 精华段落到本 fork，保留本地 Fan-Out / auto-loop / `.agent-harness/` 命名空间等魔改，产出 29 条 DoD 全绿 + 决策日志 + provenance trailer。

**Architecture:** 按批次执行 —— P0 高价值 bugfix / P0.5 Codex 补齐 / P1 skill 精华（每 skill 独立 commit）/ P2 参考文档 / 最终决策日志与 CLAUDE.md。每个 upstream commit 通过 `git cherry-pick -x -n <sha>` + sed 路径改造 + 人工 diff 复查落地，commit message 保留 `Refs: <sha7>` trailer。

**Tech Stack:** bash / git cherry-pick / sed / `tests/plugin-infrastructure/run-all.sh` / 各专项 test 套件。

## Global Constraints

- 分支：当前 `feat/agent-sup-v6.2.0`，不新开分支
- 品牌：所有 `superpowers` → `agent-harness`，`.superpowers` → `.agent-harness`（除引用 upstream repo URL 与说明性文字）
- 每个 commit 必须含 `Refs: <upstream-sha 前 7 位>` trailer；新增本地脚本无对应 upstream sha 的用 `Refs: local-<描述>`
